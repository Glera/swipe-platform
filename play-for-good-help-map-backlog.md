# Backlog: карта помощи (гео-монумент кейсов-сезонов)

Статус: **BACKLOG-концепт, зафиксирован 31.07.2026 по идее оператора.**
Наполняет этап 3 gap-карты («приют-карта»); гео-подход оператора
заменяет исходную стилизацию «острова-приюта».

## Концепт (оператор)

Карта мира с зумом; кейсы-сезоны — флажки в реальных местах; большие
скопления флажков объединяются в пульсирующие зоны, при приближении
зона распадается на отдельные флажки-кейсы.

## Ключевые решения дизайна

- **Флажок = FULFILLED-receipt с координатой реального приюта.** Карта
  — буквальная проекция append-only истории: закрытые флажки
  навсегда, ACTIVE-кейс — один живой пульсирующий флажок особого
  цвета. Пульсация зоны — от числа закрытых кейсов (receipts), не от
  «активности».
- **Личный слой**: флажки с лапкой — «здесь есть мой вклад»; тап по
  флажку — кейс, суммы, фото-отчёт, сезон.
- **Холодный старт**: v1 стартует с уровня города/региона («наша
  история начинается с одного приюта»), мир раскрывается по мере
  реального распространения — рост карты сам является нарративом.
  Карта мира с одним флажком запрещена как первый экран (ощущение
  пустоты вместо масштаба).
- **Техника: стилизованная SVG-карта, НЕ тайловый движок**
  (Leaflet/MapLibre = сотни КБ + внешний хостинг тайлов — против
  warm-start культуры). Ручная проекция координат, grid-кластеризация
  на 2–3 уровнях зума; каркас зума/пана — по образцу island.ts.
- **Приватность гранулярности**: приюты (публичные организации) —
  точка; частные заявители будущих сезонов — только город.
- Позже: слой кандидатов голосования (другой цвет флажка; кандидат ≠
  обещание — см. play-for-good-voting-backlog.md).

## Дружба в миссионном мире (обсуждение 31.07.2026)

Оператор: механизм дружбы имел потенциал в островном мире («зайти к
другу, увидеть уникальный построенный контент»), теперь потенциал
меньше. Зафиксированные новые якоря дружбы вместо UGC-витрины:

1. **Совместность на кейсе**: аватарки друзей у бара/в экране кейса
   («друзья внесли сегодня»), парная статистика («вы вместе внесли N
   лапок») — co-presence вместо навигации.
2. **Взаимопомощь**: «Попросить помочь» (этап 4) — друг проходит
   серию → фрагмент карточки тебе.
3. **Витрина следа**: «зайти к другу» = его история добра — кипсейки
   сезонов, кейсы с его лапками на карте, коллекции. Уникальный
   контент друга в новом мире — не то, что он построил виртуально, а
   то, что он сделал реально; «посмотри, скольким помогла Аня»
   эмоционально сильнее «посмотри, какой у Ани остров». Гостевой
   визит из островной меты отложен, не похоронен — если возвращается,
   гость приходит на витрину следа.

HUD при возвращении друзей (этап 3): **выбран вариант Б** —
отдельный ряд аватарок друзей ПОД баром кейса, двухрядный HUD
(решение оператора 31.07 по мокапам; пересматривает более раннее «не
возвращать в HUD»). Вариант А (микро-аватарки на заполненной части
бара) остаётся идеей для экрана кейса («друзья в этом деле»). Цена
Б — ~36px высоты над автоплеем; при необходимости ряд может
сворачиваться при скролле. Dogfood-версия (Stage 1 П4) друзей не
содержит — однорядный HUD без изменений.
