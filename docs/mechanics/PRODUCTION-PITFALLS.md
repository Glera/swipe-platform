## Девайс-грабли (проверены на живых кампаниях)

1. VP9/webm портит GPU-текстуры на Mali (старые Android); iOS не декодит.
   Только H.264.
2. AVIF = AV1 = софт-декод на части Android → стуттер. Запрещён.
3. Хардварных видео-декод сессий на слабых Android — 1–2. Не стартовать
   несколько `<video>` одновременно; вторичные декодеры — после reveal-окна.
4. `createImageBitmap(blob)` декодит в воркерах; `HTMLImageElement` —
   синхронный раст ~240мс на главном потоке при 4× CPU-троттле.
5. iOS + видео в canvas: (а) непроигранное видео не отдаёт кадр —
   стартовый кадр всегда постером; (б) заморозка rAF морозит
   canvas-композитное видео — гейтить оптимизации на «нет играющего видео».
6. DPR — главный рычаг fill-rate. Калибровка pins: 150 объектов с
   аддитивным свечением = 38fps на dpr=2 → кап 1.0 на standard.
7. Android touch-шум: drag-порог ~3px, «магнитный» радиус мержа ×1.2 —
   иначе промахи из-за коалесцирования событий в WebView.
8. Тир-детект: микро-бенчмарк решает, железные хинты только понижают
   (iOS врёт: cores=2, memory=undefined); in-app WKWebView капается.
9. У WebGL-пути обязателен context-loss guard + растровый fallback.
10. Прекомпилированные Spine-персонажи требуют baked-PNG fallback
    (prerender) для устройств вовсе без WebGL.

## Медиа-экспертиза (калибровка «стоимости эталона»)

- Прозрачный движущийся персонаж, по возрастанию веса: впечь в фон →
  Spine (вес не зависит от длины) → SBS-alpha H.264 + шейдер (эталон:
  pins) → спрайт-шит webp (эталон: дверь merge-second-board,
  11×11×120 кадров = 366KB) → animated-webp (последний вариант).
- Непрозрачное видео: H.264 Main ≤4.1, yuv420p, стороны кратны 16,
  ≤30fps, +faststart, без аудио-дорожки; звук всегда отдельным mono mp3
  через WebAudio с синком по currentTime.
- Бюджет-математика inline-ассетов: base64 = ×1.33. Кап 5MB ⇒ ~3.7MB
  бинарного сырья. Считать ДО продакшена арта.

## Практика референса (согласуется с playbook'ом и replication-process)

- Сырьё (записи, AI-генерации, .mov) — только в gitignored `masters/`
  с cloud-бэкапом; в git и в билд — только деривативы.
- Механика воспроизводится кодом по наигровке/измерениям; чужие арт,
  звук, шрифты, тексты — никогда, даже «временно».
- Цепочка деривативов фиксируется (пример: AI-видео → H.264-мастер →
  video-only mp4 + отдельный mp3).

## Build-грабли, переносимые на фабрику

- Prerender-freshness: смена spine-ассетов (даже путей) требует
  перезапекания baked-PNG до сборки.
- Дедупы аналитики переживают HMR — сбрасывать при ретестах.
- Литеральные запреты статик-гейтов (autoplay, location=) ловят и
  вендоренные либы — учитывать при выборе зависимостей.
