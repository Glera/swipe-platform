# Bus A R1 — full native reference pack

- Capture date: 2026-08-25
- Status: `reference_ready`
- Class: dependency clearing with a bounded holding buffer
- Primary reference: Bus Jam 82.6.1 (`com.nt.games.busjam`), Android
- Predecessor: [`2026-08-24-r0/lite-pack-bus.md`](../2026-08-24-r0/lite-pack-bus.md)
- Process: `reference-replication.v3.1`
- Execution authority: **none**

R1 resolves the native-reference gaps left by the clone-based R0 pack. The
Rollic build uses three-seat receivers, five staging tiles, direct tap input,
automatic loading from staging, immediate failure when the fifth staging tile
is occupied, and counted hidden tunnels from level 5. Levels 1–7 were
completed; level 8 was sampled through its first `Undo` assist.

The abstract mechanic is a deterministic planning problem over reachability,
receiver order and scarce staging capacity. Bus Jam identity, transport art,
characters, UI, exact boards, copy, economy, ads and captured media are not
shipping material. Raw bytes remain host-local; git contains only normalized
observations, digests and future acceptance contracts.

## Open, non-blocking taste gaps

The media-derived motion bands are not novice solve-time. Native `Undo` is a
reversible assist, not an explanatory solver hint. A future operator session
must decide buffer-full semantics, future-receiver visibility, original
metaphor, feed takeover comfort and session pacing before any Original profile
can be frozen.

## Hard boundary

This pack authorizes no selection, implementation, merge, publication,
deployment, runtime adoption, production dataset or economy. Exact reference
layouts may only appear in a separately authorized internal neutral Twin and
must be production-denied. Any shipping candidate requires original identity
and original datasets.
