# R0 rules dossier (24.08.2026) — точные правила кластеров shortlist'а

Источник: rule-research прогон партии R0 (sub-агент researcher'а). Все
цитаты — из публичных источников с атрибуцией; ни одна игра не
запускалась, код не скачивался, consent-стены не принимались.

## Главная находка — общий скелет четырёх кластеров

**Ограниченная зона удержания, fail = deadlock (не просто заполнение),
почти всегда 5 или 7 слотов.** Кластеры Loop/Flow, Screw, Bus Jam и
triple-tile — вариации этого скелета. Это переиспользуемый примитив для
нашей фабрики.

## 1. Loop/Flow sort — ЧЕТЫРЕ разных правила под одним ярлыком

Линейка: This is Blast! (Voodoo) → **Pixel Flow!** (Loom, $100M+ IAP,
Scopely купил долю при оценке $1B+) → волна клонов.

- **1A «бластер едет по петле и съедает линию»** (доминирующее правило:
  Pixel Flow, Colony Flow, Yarn Flow, Cube Land 3D): тап по фронтовому
  шутеру ленты → круг по конвейеру → стреляет вдоль прямых рёбер по
  первому живому таргету своего цвета («outer targets shield inner»);
  **5 slot-скамейка**, fail — «all slots full when a shooter returns»
  (slot count — параметр уровня, не константа). Полностью
  детерминировано → solver-verifiable. Длительности уровней
  опубликованы: 71–320 сек по бакетам сложности.
- **1B «груз едет в цветные ящики»** (Loop Sort/Voodoo, Loop Master):
  тап по грузовику-источнику; связка = 4 (verbatim у Loop Master; для
  Loop Sort — НЕ подтверждено, не закладывать без записи экрана);
  ограничение — ёмкость самой ленты.
- **1C** Jewel Loop: тап по connected-группе (blast-select) на доске →
  группа едет по петле в pixel-canvas.
- **1D** Chirpy Sort — вообще не loop: классический ball-sort на ветках.

## 2. Physics smash — «cannonball at a structure», БЕЗ цветового матча

Оригинал: **Smash Fest** (`com.flow.cannonball`, 16.12.2025) — вырос из
**playable-рекламы и LiveOps-мини-игры Toon Blast «Cannon Fest»** —
сильнейший документированный случай «механика родилась как реклама»
(~300K DL/день на ~50 креативах, ~90% AppLovin). Снят с Google Play
~30.07; шесть клонов перечислены с package id и датами. Правила: рeticle
без баллистики («прямая линия, no arc»), материалы (банка бьётся от
касания, жесть сбивается, камень — от прямого или падения, дерево только
падением), «упало на песок = засчитано»; fail = кончились ядра.
**Непрерывная 3D-физика — НЕ solver-verifiable**, уровни ручные.
Цветовой матч отсутствует во всех шести (у Knock Out ASO-текст врёт,
~85% уверенности).

## 3. Screw/nuts — ТРИ несовместимые семьи под одним жанром

- **Семья A (нужная): Rollic Screw Jam** — цветные toolbox'ы по 3 сокета
  + **ровно 5 запасных слотов**; путь винта: screw → spare slot →
  автоперенос в открытый toolbox своего цвета (правило из официального
  help-центра Rollic); плита снимается, когда выкручены все её винты;
  fail = 5 слотов заняты. Дискретно, solver-verifiable; все препятствия
  — явные state-машины (лёд ×3, шторки-тогглы, бомбы-счётчики,
  ротаторы «каждый ход»).
- Семья B: перевкручивание в свободные отверстия + гравитация плит —
  гибрид, чисто не верифицируется.
- Семья C: nut-sort на болтах (наш «болты» кандидат #3 из shortlist) —
  два тапа, легальность по top-of-stack, deadlock+undo вместо fail.
  Тривиально solver-verifiable. `com.nutsbolts.zgsn` из наблюдений — НЕ
  эта механика, а ball-sort рескин 17+, уже делистнут.

## 4. Bus Jam — ДВЕ под-механики; гипотеза «5 слотов» ПОДТВЕРЖДЕНА

- **A (каноническая, Rollic Bus Jam 26.06.2023)**: плоская сетка
  пассажиров; **очередь 5 слотов** (база; +2 за rewarded, у клонов до
  8); **автобус на 3 места** (тройное подтверждение, включая инвариант
  level-editor'а «пассажиры кратны трём»); тап по пассажиру с чистым
  **ортогональным** путём (A*); цвет должен совпасть с автобусом, иначе
  — в слот; fail = «нет пустых слотов». Полностью дискретно,
  solver-verifiable. Скрытые пассажиры = hidden-identity (раскрытие по
  соседству), НЕ z-стек.
- **B (Bus Traffic Fever = `jp.co.goodroid.hyper.busflow`)**: пассажиры
  ходят по петле, автобусы — в Rush-Hour parking jam; тап по автобусу со
  свободным выездом → в boarding-слот (4 или 5 — неразрешено) →
  подходящие пассажиры сходят с петли; места 4/6/8. Т.е. топовый титул
  июля — под-механика B, а жанровый канон — A.
- Дедуп: «Bus Fever (Lumi)» = `gridplus.busjam.carpuzzle` — один app.

## 5. 3D arrow cube — ДВА под-жанра, гипотеза split

- **Arrow Cube Escape (GOODROID)** — surface-паззл: стрелки на гранях
  полупрозрачного тела, пути гнутся через рёбра (жёлтые связки),
  обсталки меняют угол; fail = сердца, НЕ лоток. 3×3→9×9; до 20 минут.
- **Tap Away 3D семья** — воксельный стек «тап освобождает блок вдоль
  стрелки при чистом пути»; блокированный тап тратит ход; **бюджет
  ходов = blocks + 3** (двойное подтверждение). Оба дискретны.
- Дедуп: Cube Land Puzzle — НЕ arrow (это воксельный бластер кластера
  1A); он был у нас записан дважды под двумя именами.

## 6. Untangle rope — дискретная peg-решётка, не свободная плоскость

Tangled Rope (`com.tangled.rope`, iOS/Android один bundle, два
издателя-лейбла): концы верёвок сидят в лунках кольца/решётки; ход =
перетащить ОДИН конец в ПУСТУЮ лунку (квантовано, свободного
позиционирования нет); win = ноль пересечений; ограничение — пустые
лунки (в кольцевых уровнях — 2). «Ближе к пятнашкам, чем к Planarity» —
solver-verifiable (пересечения прямых отрезков; плетение — рендер).
Fail: на всех скриншотах живой таймер, один FAQ-цитат отрицает —
неразрешено. Цвет — НЕ правило (уровень 227 нарочно одноцветный).

## 7. Zoodoku — это Queens/Star Battle, НИЧЕГО не чистится

`com.nebula.zoodoku`: verbatim стор-описание = правило кандидата #1
shortlist'а (один зверь на регион, без совпадений строк/колонок,
без диагональных касаний, unique solution, «no numbers, no math»);
3 сердца = F2P-слой; exact-cover/CSP учебникового вида. Родословная:
LinkedIn Queens (web/social) → Meowdoku → клоны. «Zoodoku» как имя носят
≥6 разных игр — конвейер обязан джойнить по package id, не по имени.

## 8. Mahjong — два ведра, разделены чисто

- 🅐 классический солитёр (Vita Mahjong, Mahjong Blast): пары свободных
  плиток, БЕЗ лотка; fail = нет легальной пары. (Дедуп: Mahjong Blast =
  `com.nebula.mahjongtile`, дважды переименован.)
- 🅑 triple-tile с **7-слотовым лотком** (Tile Explorer ~250M DL, Tidy
  X): тап открытой плитки → лоток; тройка чистится; fail = лоток полон.
  «7» — жанровая константа (три независимых подтверждения); у Tidy X
  точный счёт не подтверждён. Занятно: Oakever издаёт по одной игре в
  каждом ведре.

## Неразрешённое (для lite/full pack'ов)

Ёмкость ящика Loop Sort · правило Chirpy verbatim · длительности в
секундах для 1B/3/4/6/8 · слоты Tidy X · «matching» у Knock Out (85%
что ASO-мусор) · слоты B-варианта Bus (4 vs 5) · сердца/ориентация
Arrow Cube · fail-условие Tangled Rope · ad-origin кластеров 3–6.
