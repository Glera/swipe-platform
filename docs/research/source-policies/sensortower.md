# Source policy: Sensor Tower

- Доступ: Enterprise-подписка организации; включены App Performance
  Insights, App Advertising Insights, Game IQ, Playliner. Персональный
  API-токен оператора хранится ТОЛЬКО в macOS Keychain Mac A
  (`p4g-research` / `sensortower-api`); чтение — `security
  find-generic-password`; в env/логи/git/чат не попадает. MCP — после
  принятия условий админом организации (отдельный операторский акт).
- Использование: read-only запросы в рамках bounded research-партий;
  бюджет ≤50 вызовов на партию; никакого unattended-поллинга (R3-правило
  charter'а: только model-free change-detector, и то после отдельного
  решения). Уважать квоту аккаунта (API Request Usage).
- Retention сырых данных: ответы API и любые выгрузки — только локально
  на Mac A (`~/.p4g-research/cache/`, вне git); срок — до конца
  соответствующей партии + 30 дней, дальше удаляются.
- Допустимая публикация derived evidence (git/issues/Lab): наши
  scorecard-оценки, ранжирования, агрегированные и перефразированные
  выводы с указанием «источник: Sensor Tower, дата»; отдельные числовые
  факты — точечно и в минимальном объёме, необходимом для решения.
- Запрещено публиковать: сырые экспорты и bulk-дампы метрик, скачанные
  из ST креативы (файлы), скриншоты платных дашбордов целиком,
  переупакованные датасеты. Креативы описываются словами/тайм-кодами и
  ссылкой на store-страницу приложения.
- Отзыв: токен отзывается в консоли ST; при подозрении на утечку —
  немедленная ротация (операторский акт).
