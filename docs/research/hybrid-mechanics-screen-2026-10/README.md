# Скрининг механик под рекламный гибрид, 19.10.2026

Вселенная: 350 самых скачиваемых игр категорий Puzzle (200) и Casual (150) за Q3-2026
по Sensor Tower, worldwide. Для каждой: retention через 1 и 2 месяца (US, когорты
июль–сентябрь 2026, facets `retention_monthly`), DAU/WAU/MAU за сентябрь (US,
`mobile_active_users`), загрузки и IAP за Q3, рост загрузок к Q2 (для Puzzle).

Планка отбора (= coin-sort / Pocket Sort): возврат через месяц ≥ 40%, через два ≥ 28%,
MAU US ≥ 250 тыс, IAP ≤ $2.5 на загрузку. Старые бренды, хабы мини-игр и 2-player
сборники отсеяны вручную.

Файлы:
- `screen.csv` — полная таблица 350 игр.
- Галерея кандидатов со скриншотами: https://claude.ai/artifact/UEQbrgAuNeyMRExos93Qth.

Главные находки:
1. **Loop Sort** (Voodoo) остаётся лидером: 72% / 57%, DAU/MAU 26%, растёт. Появился первый
   клон — **Color Sort Loop / Loop Master** (Pleasure City, HK, апр-2026): 50% / 26%,
   1.4–1.9 M загрузок в месяц на рекламе. Механика подтверждена вне Voodoo.
2. Новые чисто-рекламные тайтлы с удержанием выше coin-sort: **Tap Tile!** (triple-tile,
   71% / 82%, растёт 5 мес), **Jigsaw Drop** (61% / 35%), **Search It** (hidden objects
   без таймера, 57% / 42%), **Meowdoku** (судоку+сапёр, 4.4 M MAU US, 51% / 32%).
3. Взрывные сентябрьские запуски: **Fish Sort Puzzle** (3.5 M загрузок, 58% / 32%),
   **Bus Fever Party** (15.6 M загрузок, 56% / 37%).
4. Турецкие IAP-истории, не под гибрид: Cube Land ($5.1 M IAP в сентябре), Royal Smash! ($3 M).

Оговорки: retention Sensor Tower панельный, ниже ~250 тыс MAU шумит; рекламная выручка
API не отдаётся; рост к Q2 для Casual-категории не посчитан (Q2-список не сохранён).
