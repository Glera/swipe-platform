# Карта мобильного рынка 2025/26 (Sensor Tower), выгрузка 10.10.2026

Копия результатов анализа рынка App Store + Google Play за окт-2025..сен-2026.
Источник и полный кэш (сырые ответы API, экстракторы, MCP-сервер `sensor-tower`):
`/Users/gleb/Documents/Codex/2026-10-10/sensor-tower/` (ключ API лежит там в `.env`, сюда не копируется).

- `report.md` — полный отчёт (RU): карта ниш, драйверы, локальные рынки, 40 гипотез с вердиктами двух линз.
- `report-brief.md` — сжатая версия; тот же текст лежит в Claude Doc «Карта мобильного рынка 2025/26: ниши, драйверы, гипотезы».
- `report-data.json`, `brief-charts.json` — машиночитаемые данные отчёта и графиков.
- `verification.json` — 80 вердиктов (2 линзы × 40 гипотез): 29 ослаблены, 11 опровергнуты, 0 подтверждены без оговорок.
- `verification_second_wave.json` — вторая волна N1–N5 (из обсуждения направлений): N3, N4 ослаблены (0.00, 0.05), N1, N2, N5 опровергнуты; карточки — раздел (f2) в report.md.
- `findings/` — находки шести аналитиков (игры, приложения, страны, новички, монетизация, кросс-проверка с расчётом Codex).
- `tables/` — ключевые таблицы: динамика ниш по 12 разрезам, страны, лидеры по нишам (топ-100) и странам (топ-300), серии 4455 приложений, доля рекламных показов (США).

Граница данных: только IAP и платные загрузки магазинов; рекламной выручки, веб/D2C-платежей, Android Китая и PC/консолей нет.
Пересчёт: `python3 -I analysis/build_tables.py` в исходном каталоге; докачка — экстракторы `extract_*.py` (без `-I`).
