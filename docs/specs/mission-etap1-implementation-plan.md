## Состав работ

1. **Backend `0087` — лестница подарков** по
   `docs/specs/mission-ladder-tz-delta.md`: funding-policy v2 (правило в
   политике, лестница в контракте кейса), append-only `mission_gift_steps`
   (PK «ступень открывается один раз»), снятие unlockShare-CHECK, возврат
   нераскрытых резервов в pool при UNLOCKED, `nextStepThreshold`.
   Shared backend → Tier-2 cross-Mac review; применение миграции — GO
   оператора категории `live DB migration`. Precondition: count(*)
   preflight пустых mission-журналов (см. дельту §4).
2. **Feed вкус-слайс по канве** — 7 поверхностей
   (`docs/specs/mission-feed-delta-list.md`; сверять против канвы — она
   новее альбома в деталях): HUD-перекомпоновка (mission-бар из рейла
   челленджей → статическая сетка), плашка чужих лапок + полёт своих,
   экран кейса v3 с лестницей и «уже собрано €N», UNLOCKED/отчёт по
   канве, дейлики с лапкой-монеткой, панель C+A. Блок «медиа» кейса
   (карусели, письма приютов — новые поля контракта) допустим вторым PR.
   Bounded platform → один blind cross-provider review.
3. **Enable + founder dogfood**: двойной гейт (`VITE_MISSION_ENABLED` +
   capability `mission_dogfood`), enrolled оператор; приёмка — полный
   цикл `READY → ACTIVE → вклады → UNLOCKED → FULFILLED` в стиле канвы.
