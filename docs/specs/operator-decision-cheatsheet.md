# Операторские решения: ситуация → кнопка

Живой документ (v1, 20.08.2026). Описывает, как контуры ведут себя **сегодня**
в проде, и где известные пробелы — со ссылкой на тикет. Не contract и не
implementation authority; обновляется вместе с поверхностями.

## 1. Правка механики (fast lane)

- На карточке механики — **«Доработать механику»** → фраза (+ скриншот).
  Через минуты приходит **READY-карточка** в Telegram.
- В READY-карточке **«Проверить»** адоптирует кандидата **только в твою
  ленту** («Только мне»). Статусы всех линий — в шите «Изменения dev-ленты»
  (бейдж сверху ленты).
- Если fast lane отказал («агент не умеет») — см. §3.

## 2. Кандидат: поиграл — что дальше

- **Принять всем**: в той же карточке или в Lab «Опубликовать → Помеченные»
  → **«Подтвердить в Telegram»** (content-bound Approve). Сегодня «всем» =
  действительно всем; промежуточная ступень «сначала мне → потом всем»
  придёт со срезом 2 #118 (carrier = catalog).
- **Не принимать**: **«Доработать механику»** (новый круг с замечанием) или
  **закрыть линию в Композере** (close-семантика #121) — это и есть
  «отклонить». Явной кнопки «Отклонить» пока нет → пробел #109.
- Если карточка в ленте уже обычная, а шит показывает «только мне» — это
  устаревшая адопция, пережившая публикацию → сообщить Mac A (пробел #118
  slice 2).

## 3. Capability gap («агент не умеет»)

- Сегодня: строка висит как сигнал конвейеру; закрыть её нельзя — корень
  gap'а иммутабелен до successor'а (контур capability-successor). Это не
  твоя задача.
- Целевой процесс — **Escalation lane, #140**: отказ автоматически становится
  development-тикетом типа `mechanic`; один твой тап «делать (~день Mac B)» /
  «Неактуально»; результат возвращается тем же релизным путём и закрывает
  корень. До реализации: сказать Mac A, он заведёт тикет руками.

## 4. Правка платформы

- **«Доработать платформу»** → outbox → ≤60 с (watcher) → GitHub Issue +
  Telegram-пинг. Статус — строка «Feed shell» в шите.
- Пробел: обратной связи «Issue закрыт / выкачено» нет — статус остаётся
  «тикет создан» → #118 slice 2.
- После каждого деплоя ленты build-pin в Render обновляется (пока вручную;
  bake-сторона — Playables PR #33, backend-сторона — polish).

## 5. Отсмотр с телефона (mobile review, S1)

- Композер (`/lab?room=publish&view=orders`) → блок **«Отсмотр с телефона»**
  подключён грантом. Кандидаты приходят в телефонный инбокс; решение с
  телефона едет в Композер сам (поллер 5 с). E2E-приёмка — в test-day.

## 6. Строки шита, которые не задачи

- **«Feed shell»** — платформа: что живёт сейчас (сборка + последний
  интейк).
- **«sort/base»** — каталожная identity marble-sort (runtime —
  `marble-sort-swipe`); «данных пока нет» — read-проекция каталога ещё не
  построена (главный gap среза 2 #118).
- **Корни capability-gap** — маркировка «ждёт successor / escalation»
  вместо «устаревшая правка» → #109.

## 7. Куда писать находки

Кнопками «Доработать механику» / «Доработать платформу» — находки сами
становятся тикетами и проходят петлю. Находки копятся партией; чинятся одним
correction batch после теста, кроме блокирующих сам тест.
