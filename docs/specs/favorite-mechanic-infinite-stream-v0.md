# Бесконечный поток любимой механики — v0

- Дата: 25.08.2026. Статус: продуктовое решение зафиксировано оператором в
  чате («на старте достаточно бесконечного потока»); реализация — очередь
  платформы после hands-free пакета.
- Цель v0: игрок с любимой механикой никогда не упирается в «контент
  кончился». Разнообразие — отдельная необязательная струя, не условие
  бесконечности.

## Решение v0 (минимальный состав)

1. **Два класса контента.**
   - *Новизна* (новый вариант/твист/арт): Labs + операторский вкусовой
     Approve — как сейчас.
   - *Рефилл утверждённого варианта*: без ручного гейта. Approve варианта —
     вкусовая авторизация всего его параметрического семейства. Гейты
     машинные: solvability, конверт сложности, дедуп по
     `(fingerprint_version, series_fingerprint)`, ревалидация
     manifest/LevelSpec/runtime-замыкания (всё уже существует в аллокаторе).
2. **Гарантия = floor.** Для (игрок, любимая механика) сервер держит «впереди
   ≥N невиданных серий» в персональном runway. Просадка → авто-запрос рефилла
   фабрике (deterministic seed → серии LevelSpec → машинные гейты → catalog
   admission → runway). Фабрика недоступна/медленна → существующий safe
   fallback замороженной continuation-цепочки. Дедуп исключает повторную
   выдачу виденного.
3. **Сложность v0:** фабричная монотонная кривая с периодическими
   передышками, объявляемая генератором. Без per-player адаптации.
4. **Future-proof бесплатно (единственная уступка будущему):** каждая
   сгенерированная серия несёт метаданные у истока —
   `{mechanicId, variant, seed, generatorVersion, difficultyCurve}`
   (+`featureTags[]` опционально, если генератору они и так известны).
   Разметка при генерации бесплатна; ретроспективная — дорога.

## Сознательно отложено (включаем по мере роста, отдельными решениями)

- Satiety-сигнал усталости (тренд completion/skip/dwell) — сперва shadow.
- Skill-бакеты per (игрок, механика) из существующего results-wire и окно
  сложности для ветеранов.
- Выбор по невиданным `featureTags` («новое разнообразие, которого он ещё
  не видел»).
- Probe-слоты возврата уставшей механики при появлении нового approved
  варианта (+cooldown).
- Демандный заказ разнообразия для Labs от исчерпания тег-пространства
  когортой ветеранов.

## Границы

- Замороженная continuation-цепочка v1 не меняется: всё новое — входы в
  существующий slot decision и его immutable sidecar (объяснимость каждой
  выдачи сохраняется).
- Hard-гейты включения (`capabilities.levelSeries=false`, manifest-bound E2E,
  production bootstrap, device/event-order, p95) остаются в силе — v0 их не
  обходит, а проходит.
- Пилот: одна механика с самым надёжным параметрическим генератором, один
  утверждённый вариант end-to-end до runway.
