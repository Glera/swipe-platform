# p4g-platform-workspace

## Commands
- `npm run verify` — fast full verify (types + unit tests + build + contracts)
- `npm run test:all` — unit tests across all packages (187 tests)
- `npm run test:e2e` — full nightly E2E tests (browser required)
- `npm run test:e2e:smoke` — quick smoke E2E tests
- `npm run build:all` — build all packages in dependency order
- `npm run check:all` — TypeScript check all packages
